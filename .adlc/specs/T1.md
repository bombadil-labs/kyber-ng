# T1 — Loop 1: The Unified Event Layer (rev 2)

**Rev 2 folds in the P1 premortem findings (2026-08-06, delegated adversarial review):**
pinned wire envelope, float-only timestamps (D14), DeltaSet element type, Kyber.Keys API
heads, door policy on unsigned deltas, and AC8 pinning the event vocabulary.

## Context

Kyber is being rewritten on rhizomatic ground: every event is a signed, content-addressed,
loam-compatible claim (SPEC.md, spec/00-overview.md — the unification, D1). This ticket
implements the event layer: the keyring, the claim templates, the delta set, and the store
door — proven by ExUnit tests. The substrate (the rhizomatic Elixir witness at
deps/rhizomatic) is FROZEN and consumed as a git dep; it is never edited from here
(spec/03-substrate.md). Verified witness contracts this ticket builds on:
`Rhizomatic.Profile.parse_claims/1` is claims-only and **closed** (rejects `sig`/`id`) and
parse-only (no serializer); `Rhizomatic.Signer.sign/2` returns `{:ok, sig_hex}`;
`Rhizomatic.Signer.verify/3` returns a **boolean**; the witness rejects native integer
timestamps (D14 — floats only).

## Wire envelope (pinned)

The door's input and the loam-append shape — kyber's own thin envelope over the witness
(the witness has no envelope concept):

```json
{ "id": "<lowercase hex content address>",
  "claims": { "timestamp": 1754512345678.0, "author": "ed25519:<hex>", "pointers": [...] },
  "sig": "<lowercase hex ed25519 signature>" }
```

## Requirements

1. **Kyber.Keys** — pinned public API (Verification: `mix test test/keys_test.exs`); file
   I/O confined to this module; seeds are 32 raw
   bytes, hex-encoded (spec/02-identity.md):
   - `mint_agent_seed(home_dir)` → `{:ok, seed_hex} | {:error, _}` — creates home, writes
     `agent.seed` 0600 (hex), never prints.
   - `load_agent_seed(home_dir)` → `{:ok, seed_hex} | {:error, _}` — reads it; `KYBER_SEED`
     env (hex) imports on first load when no file exists.
   - `import_human_seed(seed_hex, home_dir)` → `:ok | {:error, _}` — stores the human's seed
     0600 (the key kyber signs human-origin events with).
   - `author_for_seed(seed_hex)` → `"ed25519:<hex>"` (via `Rhizomatic.Ed25519.public_key`).
   - `sign(claims, seed_hex)` → `{:ok, sig_hex} | {:error, _}` — wraps
     `Rhizomatic.Signer.sign/2`.
   Verification: `mix test test/keys_test.exs`.
2. **Kyber.Events** — pinned builder names, each returning `{:ok, {claims, sig_hex}} |
   {:error, _}`, with the EXACT pointer structures of spec/01-events.md §2 (roles, targets,
   contexts; no extra, no missing):

   ```elixir
   message_received(human_seed_hex, ts, message_id, channel_id, session_id, content)
   prompt_annotated(agent_seed_hex, ts, annotated_delta_id, notes)
   llm_response(agent_seed_hex, ts, annotated_delta_id, content)
   message_sent(agent_seed_hex, ts, response_delta_id, out_message_id, channel_id, content)
   tool_exec(agent_seed_hex, ts, during_delta_id, tool_id, args, result)
   ```

   Timestamps are **float milliseconds** (D14: the witness rejects native integer terms;
   builders convert explicit integer args to floats themselves — never coerce inside the
   witness). Verification: `mix test test/events_test.exs`.
3. **Kyber.DeltaSet** — grow-only set of **full signed deltas** (`{claims, sig_hex}`) keyed
   by content id, so replay can re-verify (spec/04-persistence.md §1–§2): `new/0`,
   `merge/2` (union), `member?/2` (by id hex), `size/1`.
   Verification: `mix test test/delta_set_test.exs`.
4. **Kyber.Store** — the door (spec/04-persistence.md §3):
   `append(wire_json_map)` → `:ok | {:error, reason}`. Extract `"claims"` → parse via
   `Rhizomatic.Profile.parse_claims/1`; recompute the id via `Rhizomatic.Delta`; refuse when
   it mismatches the envelope's `"id"`; **refuse unsigned deltas (no `"sig"`) — D1**; verify
   via `Rhizomatic.Signer.verify/3` (boolean — the store converts to `{:error, :bad_signature}`);
   then merge into the set. Reject (a) a tampered id, (b) a wrong-key signature, (c) an
   unsigned delta. Verification: `mix test test/store_test.exs`.
5. TDD throughout; no Process.sleep in tests (assert_receive/3, catch_exit, or explicit
   state polling); `mix format` clean.
   Verification: `grep -r "Process.sleep" test/` finds nothing, and `mix format --check-formatted` exits 0.

## Acceptance Criteria (each names its verification method)

- **AC1 — The event layer compiles and the whole suite passes.**
  Verification: `mix test` exits 0 with no skips.
- **AC2 — Every emitted delta's id recomputes from its canonical bytes, and its signature
  verifies.**
  Verification: `mix test test/events_test.exs` asserts, for each Kyber.Events delta, that
  `Rhizomatic.Delta` recomputes the same id from the canonical bytes and `Rhizomatic.Signer`
  verifies the signature.
- **AC3 — message_received is signed by the human's key; llm_response and message_sent are
  signed by the agent's key.**
  Verification: `mix test test/events_test.exs` asserts each delta's `claims.author` equals
  `Kyber.Keys.author_for_seed/1` of the expected seed (human vs agent).
- **AC4 — DeltaSet.merge is commutative and idempotent on a 3-delta fixture.**
  Verification: `mix test test/delta_set_test.exs` asserts `merge(a, b) == merge(b, a)` and
  `merge(s, s) == s` for the fixture sets.
- **AC5 — The door rejects a tampered id, a wrong-key signature, and an unsigned delta.**
  Verification: `mix test test/store_test.exs` asserts `Kyber.Store.append/1` returns
  `{:error, _}` for all three cases.
- **AC6 — The claims of a signed message_received, extracted from the wire envelope and
  parsed via `Rhizomatic.Profile.parse_claims/1`, re-serialize (via `Rhizomatic.Delta`
  canonical bytes) to identical canonical bytes — the loam-compatibility proof.**
  Verification: `mix test test/events_test.exs` compares canonical bytes before and after.
- **AC7 — No Process.sleep anywhere in test/.**
  Verification: `grep -r "Process.sleep" test/` finds nothing.
- **AC8 — Each builder emits exactly the pointer structures of spec/01-events.md §2: for a
  canonical fixture, the emitted pointers match the template role-by-role, target-by-target,
  as an unordered set (no misspelled roles, no dropped `session` pointers, no extra
  pointers).**
  Verification: `mix test test/events_test.exs` asserts pointer-set equality for all five
  builders against the spec templates.
