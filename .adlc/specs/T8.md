# T8 — Loop 8: The Operator Surface — a CLI for the whole stack (escript)

## Context

Every loop so far delivered MODULE APIs. T8 gives the harness a FACE: a `kyber` escript
(stdlib Mix escript — ZERO new dependencies; the only mix.exs change is a ONE-TIME
additive `escript:` stanza, pinned below) driving the full stack. The dispatch core is
PURE-ish and testable: each command function returns `{status, message}` and never calls
`System.halt/1`; `main/1` is a thin wrapper that prints and halts. Tagged failures print
as clean one-liners — never a crash stacktrace. Exit codes pinned: `0` success, `1`
operational error (any tagged `{:error, _}`), `2` usage error (bad argv / unknown
command). Store-down answers a clean message and exits 1.

**Escript mechanics (pinned):** `escript: [main_module: Kyber.CLI]` in `def project`.
`mix escript.build` compiles the app + embeds the deps' beams; `config/config.exs` is
compiled into the app (the default `:kyber, :log_path` and `keyring_dir` are baked in at
build time). The escript runs OUTSIDE the project dir. A `--log <path>` global flag
overrides the log path (via `Application.put_env` BEFORE `Application.ensure_all_started`
— the operator/test override; the store's log must be selectable at runtime).

**CLI shape (pinned):**

```
kyber [--log <path>] <command> [args]
  view                                   sorted claims, one per line: <id_hex> <role> <author[:8]> <ts_decimal>
  ingest <source.json> --keyring <dir>   the T4 source map -> Harness.ingest; prints the claim id
  render <vault_dir>                     Vault.render; prints the report
  refresh <vault_dir>                    Vault.refresh; prints the report
  export                                 Federation.export; prints the wire text
  import <wire.jsonl>                    Federation.import; prints the import report
  migrate <legacy.jsonl> --keyring <dir> Migration.migrate; prints the migration report
  help | (no args)                       usage
```

## Requirements

1. **Kyber.CLI** — Verification: `mix test test/cli_test.exs`.

   ```elixir
   main(argv) -> never returns (prints + System.halt)
   run(argv) -> {status, message}        # PURE-ish dispatch — no halt, no IO
   ```

   `run/1` parses argv (a `--log` global flag consumed BEFORE the command; subcommand
   flags after), dispatches to the command's function (each returns `{status, message}`:
   `{:ok, message}` → exit 0; `{:error, message}` → exit 1; `{:error, :usage, message}`
   → exit 2), formats every `{:error, _}` tag as a clean one-liner (`store not running`,
   `no agent seed`, `no legacy log: <path>`, `malformed source`, ... — the tag atoms
   map to pinned human text). `main/1` = `run/1` → print → `System.halt`. The commands:
   `view` (Harness.view/0 → the pinned line format), `ingest` (File.read! → JSON.decode →
   Harness.ingest/2 with the keyring), `render`/`refresh` (Vault), `export`/`import`
   (Federation), `migrate` (Migration). A missing file is a tagged error, never a raise.
   `help`/unknown → usage text, exit 2.
2. TDD; no Process.sleep; `mix format` clean. Verification: `grep -r "Process.sleep"
   test/` finds nothing, `mix format --check-formatted` exits 0.
