# T5 — Loop 5: Federation — the wire speaks to itself (export/import)

## Context

T1–T4 built the claim lifecycle: emit → sign → persist → view. A claim now lives on one
instance; T5 lets it JOURNEY — `Kyber.Federation` exports the store as wire JSONL and
imports wire JSONL through the door (every signature re-verified by the frozen witness,
union dedup, per-line reporting). This is the loam-compatible exchange in miniature (a
federation peer in another language parses exactly this text — the wire bytes are the
contract, pinned in T3) — and the import machinery IS the migration path: spec/07's
legacy-log unification will translate legacy shapes to wire and feed them through
`import/1`, so T6 can reuse it wholesale.

Import reuses the T2 replay policy (report, never halt, never repair) and the T4 harness
shape (store-down guard, tagged tuples, no new process — the app-started DurableStore is
the sink).

## Requirements

1. **Kyber.Federation** — Verification: `mix test test/federation_test.exs`.

   ```elixir
   export() -> {:ok, jsonl_text} | {:error, reason}     # store-down -> {:error, :store_not_running}
   import(jsonl_text) -> {:ok, import_report} | {:error, reason}
   import_report() -> %{imported: non_neg_integer(), refused: [line_no()], skipped: non_neg_integer()}
   ```

   `export/0`: the store's delta set as wire JSONL — ONE pinned envelope per line
   (`Wire.envelope({claims, sig})` rebuilt from the set's `{claims, sig}` values,
   `Wire.encode`, no trailing blank line), DETERMINISTIC order (sorted by id_hex — the
   same sort view/0 uses, so export is stable and byte-comparable).
   `import/1`: stream the text line by line; per line: empty/blank → skipped; `Wire.decode`
   failure → `refused` (line number); decode-ok → `DurableStore.append` — `:ok` →
   `imported`, door refusal (duplicate → union no-op counts as `skipped`, any other
   refusal → `refused`). NEVER halts on a bad line; NEVER repairs (torn text is refused,
   not fixed); the report is returned. Store-down before any append →
   `{:error, :store_not_running}` (the T4 guard shape). A line that decodes but whose
   envelope the door refuses for ANY reason is `refused` with its line number — a
   tampered or foreign claim cannot land silently.
   `import_report/0`: the last import's report (mirroring `replay_report/0` — a live
   observable, reset to zeros by each import).
2. TDD; no Process.sleep; `mix format` clean. Verification: `grep -r "Process.sleep"
   test/` finds nothing, `mix format --check-formatted` exits 0.

  stored claim appears as its pinned envelope, sorted by id_hex; the text round-trips

- **AC3 — Cross-instance round trip: instance A ingests two claims (T4 Harness: one
  human, one agent) → `export(A)` → instance B imports → both claims re-verify through
  B's door (admit `{:ok, _}`), are present in B's set, and `Harness.view(B)` equals
  `Harness.view(A)` (view-identical).** Verification: `mix test test/federation_test.exs`
  (two stores on separate tmp log paths; import twice → dedup: the second import reports
  `skipped: 2, imported: 0`).
- **AC4 — Byte-identical union round trip: export(A) imported into B then exported
  equals export(A) byte-for-byte** (the union of the same claims sorts the same).
  Verification: `mix test test/federation_test.exs`.

  line (valid JSON, invalid signature — e.g. a claim signed by a foreign key), a
  NON-ENVELOPE line (`"[]"`), and valid lines interleaved → valid lines land, each bad
  line is reported with its line number, import_report shows exactly
  `%{imported: n, refused: [torn_no, tampered_no, nonenvelope_no], skipped: 0}` (plus
  dedup skips where pinned).** Verification: `mix test test/federation_test.exs`.
- **AC6 — Store-down is a tagged tuple: with :kyber stopped, `export/0` and `import/1`
  return `{:error, :store_not_running}` — never a crash.** Verification: `mix test
  test/federation_test.exs` (stop the app, assert the tag, re-boot).
- **AC7 — import_report is a live observable: the report shape is
  `%{imported: n, refused: [line_nos], skipped: n}` (line numbers 1-based), reset by
  each import, readable between imports (initially all zeros).**
  Verification: `mix test test/federation_test.exs`.
