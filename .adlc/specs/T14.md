## The slice

The agent runs: an event-driven reactor that closes the loop the T12/T13 slices left open —
refusals come back to the model, prompts are answered as store deltas, policy can evolve
without restart, and the boundary is stated instead of implied.

## Deliverables (draft)

- `lib/kyber/agent/reactor.ex` — the event-driven loop (T14 title): fires on deltas, budgets
  per turn, gated initiation (the Oracle seed).
- The refusal loop: a gate-refused ToolCall resumes the model's turn with the reason
  (T12 carry #1 — CLOSED pre-merge 2026-08-07: engine "decides" subscription + refusal
  routing; tool_chain 9/0, proven live by the AC4 run). The reactor still owns the
  budgeted, gated loop this slice is named for.
- Prompt-answer-as-delta: the `prompt` policy's answer is an attested store delta; the
  decision derives from store state (determinism clause preserved); no-answer-within-T →
  refuse; the answering key is restricted to human authority (T12 carry #2).
- Idempotence enforcement: idempotence as a registry field; non-idempotent actions refuse
  allow-listing without explicit override; AC1 sub-assertion for the pre-persistence re-fire
  window (T12 carry #3).
- URL policy for http actions: scheme/host allow-list or loopback/link-local deny-list,
  resolved at boot like the gate; redirect targets re-validated (T12 carry #4).
- Policy epochs: gate policy reload without restart; revocation is retroactive — a stored
  allow decision does NOT outrank a later revocation (T12 carry #5).
- Memory-read permission seam: the retriever is gated like actions; a refused memory read
  degrades to a precision-only turn, never a dead turn (T13 carry).

  THIS spec (mechanics, confounds + instruments in the planning-rumble reference).

  a per-finding delta log; surviving H findings are user-visible accepted risks in the
  slice report, never silent. The carry register is a required input.
