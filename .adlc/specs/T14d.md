# T14d — Boundary Enumeration: Failure-Mode Inventory

Status: OPEN (light ceremony — rumble for the design cells, ONE deterministic
build, no blind taste). Parent: T14c (`45a8eb9` on main, merged `4058707`).
Rails: carried (frozen `deps/ spec/ SPEC.md mix.exs config/`; no Process.sleep;
canonical spellings; content-derived identity; merge-is-union; retraction-is-negation).

## Scope

The systematic inventory of the policy layer's failure modes — every gate × input
interaction, every tool boundary, every engine path — pinned to an exact behavior
and witnessed by a deterministic test. The slice's deliverable is the MATRIX: a
cell per boundary case, each with a pinned outcome and a fails-when-absent leg.

In scope: the memory_policy clause table's undecidable cells (the T14c deferred
fork×undecodable + its neighbors), url_policy edge inputs, the tool boundary caps
(fs.read output, fs.list entries, web_fetch size/timeout, shell containment,
http.get redirects), the engine path pins (constructor fail-hard, replay
decode-failure raise — the T14c taste cells), the store/epoch mechanics
(fork-precision beyond two live heads, merge, retraction), and precision bounding
(exact values, exact behaviors — no "reasonable cap" language).

Out of scope: the M5 engine verdict bug (engine.ex:161 atom-vs-string guard —
the separate engine-decides slice; live config discipline still applies), URL
policy redesign, new tool surfaces, the operational/live ACs (all cells here are
deterministic), the channel adapter (Liet's import).

## Open decisions (the rumble's dispose list)

D1. A1 fork×undecodable: abstain-allow (status quo) / fail-closed refuse (forked
reason) / refuse with a dedicated reason string.
D2. A4 ungoverned×undecodable: abstain-allow / fail-closed refuse (ungoverned
reason).
D3. B7 + D3: memory.read under a forked epoch (refuse-before-resolve?) and the
>2-live-heads behavior (reuse `{:error, :forked}` / distinct error / treat as
forked regardless of count).
D4. D4 concurrency cap value + behavior at cap.
D5. A9/A10 url_policy nil/malformed/empty: refuse / error / allow.
D6. B1 fs.read cap value + past-cap behavior.
D7. B2 fs.list cap value + over-cap behavior.
D8. B3 shell containment rule + not-contained outcome.
D9. B4 web_fetch size/timeout values + behavior.
D10. B8 memory.read wrong-typed args outcome.

## Acceptance criteria

AC1 — Gate matrix: every Class A cell's outcome pinned and witnessed; the
clause-table cells (A2-A8) keep their T14c legs, the open cells (A1, A4, A9-A11)
get new legs. Fails-when-absent: deleting any clause-table row or matrix leg
fails the suite.
AC2 — Tool bounds: every Class B cap pinned to an exact value with an exact
behavior + a deterministic test at and past the cap. Fails-when-absent: removing
a cap or its leg fails the suite.
AC3 — Engine pins: C1 constructor-failure fails hard (a test injects the
`{:error, _}` path and asserts the hard failure, NOT a silent skip); C2/C3
witnessed. Fails-when-absent: re-introducing a silent skip passes nothing.
AC4 — Epoch mechanics: D1-D4 witnessed, including the >2-live-heads cell.
Fails-when-absent: weakening fork detection fails.
AC5 — Precision bounding: every cap value appears exactly once in the plan and
is referenced by its test (no duplicated literals, no "reasonable" language).
