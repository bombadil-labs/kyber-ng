# T6 — Loop 6: Migration — the legacy log becomes claims (spec/07)

## Context

The ORIGINAL mission lands: kyber's pre-rhizomatic delta log is unified with
rhizomatic/loam deltas. The legacy repo (~/repos/kyber) writes `deltas.jsonl` — one
`Kyber.Delta.to_map/1` map per line, Jason-encoded (store.ex `write_line/2`): string keys
`id`, `ts`, `origin`, `kind`, `payload`, `parent_id` (payload is arbitrary JSON — a map
of memory content, a string, etc.). Legacy deltas are UNSIGNED — migration cannot
fabricate signatures. The archivist answer (pinned): each legacy delta becomes a claim
SIGNED BY THE AGENT KEY (the harness attests "this delta existed in my history"); the
legacy identity lives in the claim's pointers; the timestamp is the legacy ts (coerced to
float per D14 — translate_line IS the builder here). No signature is fabricated: the
archivist signature is the harness vouching for its own past.

T5's architecture pays off: migration is a PURE translator feeding the existing pipeline —
`Kyber.Migration.migrate/2` translates the legacy log to wire text and hands it to
`Federation.import/1` (the SAME door, the SAME dedup → re-migration is idempotent, the
SAME reporting). The claim shape (pinned): `%{timestamp: float, author: agent_pubkey,
pointers: [%{role: "legacy", target: {:entity, "delta:<legacy_id>", "legacy"}}, %{role:
"kind", target: {:string, kind}}, %{role: "origin", target: {:string, origin}}, %{role:
"parent", target: {:string, parent_id}}, %{role: "content", target: {:string,
JSON.encode!(payload)}}]}` — every legacy field preserved, reject-never-repair: a legacy
line that does not parse or lacks a required key is refused with its line number, never
silently dropped.

## Requirements

1. **Kyber.Migration** — Verification: `mix test test/migration_test.exs`.

   ```elixir
   migrate(legacy_path, keyring_dir) -> {:ok, migration_report} | {:error, reason}
   translate_line(legacy_map) -> {:ok, {claims, sig}} | {:error, reason}   # PURE
   ```

   `translate_line/1` (PURE — no I/O, no store): takes the DECODED legacy map (string
   keys), validates the required keys (`id`, `ts`, `kind` — `origin`/`parent_id`/`payload`
   optional, absent → nil → omitted from pointers), coerces `ts` to float (`1.0 * ts`,
   D14 — translate_line is the builder), builds the pinned claim shape, signs with the
   AGENT seed (via `Keys.load_agent_seed/1` + `Keys.sign/2` — the archivist). Returns
   `{claims, sig}` — the same shape the Events builders return.
   `migrate/2`: store-down guard FIRST (`Process.whereis(Kyber.DurableStore)` →
   `{:error, :store_not_running}`); `File.stream!(legacy_path)` (LAZY — legacy logs can
   be large memory logs) → per line: `JSON.decode` → `translate_line` → `{:ok, {claims,
   sig}}` → `Wire.envelope/1` + `Wire.encode/1` → a wire line (collect); `{:error, _}` →
   `legacy_refused ++ [line_no]` (1-based, never fatal). Then
   `Federation.import(wire_text)` — all collected lines at once. The result:
   `%{imported: n, refused: [line_nos], skipped: n, legacy_refused: [line_nos]}`
   (migration_report = import_report + the legacy-side refusals). A store-down from the
   import (mid-migration) passes through as `{:error, :store_not_running}`. An empty or
   absent legacy file: `File.stream!` on a missing path → `{:error, {:no_legacy_log,
   path}}` (a tagged tuple, never a crash); an EMPTY file → `{:ok, %{imported: 0,
   refused: [], skipped: 0, legacy_refused: []}}`.
2. TDD; no Process.sleep; `mix format` clean. Verification: `grep -r "Process.sleep"
   test/` finds nothing, `mix format --check-formatted` exits 0.
